# Code of conduct

Treat contributors and users with respect. Discuss ideas and code on their
merits. Welcome questions and different levels of experience.

Harassment, threats, discriminatory abuse, and publishing another person's
private information are unacceptable in project issues, pull requests, and
other project spaces.

Maintainers may edit or remove harmful content, close discussions, or restrict
participation. Enforcement should reflect the behavior and its impact, with
an explanation where doing so does not expose private information.

Use GitHub's Report content tools for abusive content. For concerns requiring
maintainer attention, use an available contact method on
[@jasonm4130's profile](https://github.com/jasonm4130). Do not repost private
information to report a violation.
