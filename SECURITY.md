# Security policy

Report suspected vulnerabilities privately through
[GitHub security advisories](https://github.com/jasonm4130/wattop/security/advisories/new).
Include the affected version, impact, and minimal reproduction. Do not post
credentials or real session transcripts in the report.

wattop is an early-stage project. Security fixes target `main` and the latest
release; older versions do not receive separate maintenance. Response times
depend on maintainer availability.

## Local data

wattop reads local coding-agent session files and process information. Session
paths, identifiers, model names, and usage can appear in its display and JSON
output. Review diagnostics and screenshots before sharing them.

Pricing refreshes fetch a public upstream table. Cost estimates are not billing
records or subscription balances. Read [limitations](docs/limitations.md) before
relying on hardware or usage measurements.
